# DevQuest

A Python terminal-based adventure game built as a personal coding challenge.

## About

DevQuest started as a personal experiment to build something without waiting until I knew everything. The goal was simple: pick a messy problem, keep moving, and figure things out along the way.

This project represents the first completed version of the game and focuses on building a clean interactive terminal experience using Python.

## Features

* Interactive main menu
* Create player
* View player profile
* Exit system
* Loop-based game flow
* Function-based architecture
* Passing data between functions using return values and arguments
* Basic input validation

## What I learned

While building this project, I practiced:

* Functions
* Function calls
* Return values
* Function arguments
* Variable scope
* Loops
* Program flow

## Tech stack

* Python 3
* Terminal / Console application

This project is part of my journey to become someone who can enter a messy problem and keep moving.
